# Optional Google owner connection

This release provides private owner review browsing. It does not turn a Maps link into a downloadable review feed or add Google reviews to public carousel storage. Live Google authorization is unverified in this candidate; tests use synthetic mocked responses.

1. Use an eligible, approved Google Business Profile project for your own authorized operation. Check [prerequisites](https://developers.google.com/my-business/content/prereqs) and [OAuth documentation](https://developers.google.com/my-business/content/implement-oauth). Approval is not guaranteed. Agencies/software providers must review both supplemental-project and automated-access restrictions in [Google's policies](https://developers.google.com/my-business/content/policies); this is not a workaround for offering clients indirect API access.
2. Enable Google My Business API, My Business Account Management API and My Business Business Information API as appropriate for the approved project. Configure OAuth consent and an OAuth **Web application** client. Allow your testing account if the consent application is still in testing.
3. On a publicly reachable HTTPS WordPress site, open **Google Reviews → Synchronization**. Copy the exact callback URL displayed there into the client's Authorized redirect URIs. Paste the client ID and secret into the private configuration form, save, then choose **Connect Google**. Do not paste credentials into chat or public issues.
4. Sign in with an account authorized to manage the verified business. Select its account and location, check the name/address, explicitly confirm business identity and save. Similar names require checking address and account; Place ID and public URL alone do not authenticate ownership.
5. Choose **Browse original owner reviews** from the saved location. Responses contain up to 50 reviews per page; use Next for subsequent pages. Original author/text/rating/time are shown only when supplied. The source total is separate from the number of locally imported reviews.
6. Select 12h/24h/48h/weekly/manual refresh. Scheduled Google refresh fetches only the first page into a 15-minute cache. Subsequent pages load on demand. Nothing is added to the public reviews table; there is no permanent Google archive or public export.
7. **Disconnect** removes local tokens and invalidates cached access, and attempts token revocation at Google. If network revocation fails, also remove access in your Google Account security settings. Uninstall always removes local Google secrets, even when other data is retained.

Client secrets and refresh/access tokens are encrypted with AES-256-GCM using WordPress authentication salts. Keep database backups private. Rotating salts requires reconnection. PHP OpenSSL is required for this optional connection. Browser status, diagnostics, settings exports and logs omit secrets. Remote response bodies are not used as error messages.

Troubleshooting: an approval/permissions failure means check project approval, enabled APIs and verified-business role; an expired authorization means reconnect; quota failure means wait and inspect your project limits. Short OAuth testing-mode token lifetimes are controlled by Google. WP-Cron needs traffic or an external cron job. Source failures preserve existing authorized local reviews.
