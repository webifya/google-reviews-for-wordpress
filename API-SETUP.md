# Google Business Profile Manager connection — 1.6.0-rc.1

1. Back up WordPress, install this ZIP through Plugins → Add New → Upload Plugin, and replace the existing Google Reviews for WordPress installation. Do not uninstall it first. Saved reviews, locations, designs and shortcodes are preserved.
2. Your publicly reachable WordPress site must use HTTPS. In Google Reviews → Settings, copy the displayed authorized redirect URI.
3. In your approved Google Cloud project, enable My Business Account Management API, My Business Business Information API, and the Google My Business API used for reviews. API access approval and a verified managed business are required; Manager access alone is insufficient. Follow Google's current API prerequisites and OAuth consent requirements. If the OAuth app is in external Testing mode, add your signed-in manager as a test user; refresh tokens may expire after seven days. Use a properly configured production consent app for continued operation.
4. Create an OAuth client with application type Web application. Add the exact redirect URI copied from WordPress. Enter its client ID and secret only in the private WordPress Settings form, then save. Secrets are encrypted with your WordPress authentication salt and never returned to the browser. Maintain your WordPress salts; changing them makes saved credentials unreadable.
5. Click Connect Google Manager account. Sign in with the account that manages Menjar Financial and authorize Business Profile access. Return to WordPress Settings and click Choose managed Google business. Select the account, click Show businesses, then select Menjar Financial. If not on the current page, use More accounts / More businesses.
6. Choose your existing Menjar Financial listing in Update existing listing to preserve existing widget assignments. Automatic Place ID matching is also supported. Connecting first checks verified-location review access. It does not import Google content into your permanent review archive.
7. View API reviews to browse all pages of available reviews (50 per Google API page), including rating-only reviews and business replies. The counts are Google's reported totals, not a fabricated download count. No live Google account was used to validate this release; automated checks use synthetic transport fixtures.
8. If your applicable Google agreement and authorization permit website display, enable the live website display choice. Manager status and the acknowledgement do not grant additional display or storage rights. In Widgets, use Connected reviews, select only the managed Google businesses for this API widget and set the review limit high enough to include the available reviews. Keep the existing shortcode on the page. API content loads through no-store responses after page load; multiple API pages are followed automatically up to the configured widget limit. Google attribution is retained. The widget displays the configured rating and ordering selection.

API review content is encrypted and cached for at most 15 minutes for request performance. It is refreshed on demand after expiry; it is not a permanent review archive or daily/three-day download. No Node.js, Chromium, Places API key or scraping worker is needed for this connection. Existing browser collector and licensed/imported stored sources remain available separately. Failed API requests do not overwrite saved content with fixtures.

Errors: reconnect on expired/revoked authorization; check project approval, the three enabled APIs, verified-business permissions and quotas for access errors. Public API calls have a configurable daily site budget (500 by default); temporary cache hits do not spend requests. Connection changes invalidate cached content and widget authorization. After reconnecting, clear your WordPress/CDN page cache so the current widget token can load.

References: [Google prerequisites](https://developers.google.com/my-business/content/prereqs), [review pagination](https://developers.google.com/my-business/reference/rest/v4/accounts.locations.reviews/list), [content policies](https://developers.google.com/my-business/content/policies), [OAuth testing token expiry](https://developers.google.com/identity/protocols/oauth2#expiration).
